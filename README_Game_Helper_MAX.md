# 🎮 Game Helper MAX — Telegram-бот с адаптивным обучением

## 👨‍💻 О проекте

Я создал **Game Helper MAX** — Telegram-бота, который помогает изучать и проверять знания по играм через интерактивные задания.

Главная идея проекта — объединить обычные игровые гайды, викторины, систему прогресса и машинное обучение в одном Telegram-боте.

Бот работает через кнопки Telegram, поэтому пользователю не нужно постоянно вводить команды вручную.

---

## 🎯 Цель проекта

Моя цель — создать интерактивного помощника, который:

- помогает изучать информацию об играх;
- предлагает гайды;
- проводит викторины;
- сохраняет результаты;
- начисляет XP и повышает уровень;
- анализирует результаты с помощью ML;
- определяет текущий уровень игрока;
- определяет слабую тему;
- рекомендует, что изучить дальше.

---

## 🎮 Поддерживаемые игры

В проекте сейчас есть три игры:

1. **Poppy Playtime**
2. **Minecraft**
3. **Roblox**

Для каждой игры доступны собственные гайды и вопросы викторины.

---

## 📚 Гайды

В проекте подготовлено **30 гайдов**:

- 8 гайдов по Poppy Playtime;
- 14 гайдов по Minecraft;
- 8 гайдов по Roblox.

Гайды разделены по играм и открываются через интерактивные Telegram-кнопки.

---

## 🧠 Викторина

В проекте используется **90 вопросов**:

- 30 вопросов для Poppy Playtime;
- 30 вопросов для Minecraft;
- 30 вопросов для Roblox.

Для каждого вопроса есть четыре варианта ответа:

**A / B / C / D**

Вопросы разделены на четыре уровня сложности:

- Easy
- Normal
- Hard
- Expert

После ответа бот сразу определяет результат и обновляет статистику.

---

## 📈 XP и уровни

За прохождение викторин пользователь получает XP.

В проекте предусмотрены уровни от 1 до 8.

Используемые пороги XP:

| Уровень | XP |
|---|---:|
| 1 | 0 |
| 2 | 50 |
| 3 | 100 |
| 4 | 200 |
| 5 | 350 |
| 6 | 500 |
| 7 | 750 |
| 8 | 1000 |

Таким образом, прогресс пользователя можно отслеживать не только по количеству правильных ответов, но и по уровню.

---

## 🤖 Машинное обучение

Одна из главных частей проекта — **ML-анализ результатов**.

Для анализа используется модель **Decision Tree Classifier** из библиотеки `scikit-learn`.

Модель получает характеристики игрока, например:

- процент правильных ответов;
- количество пройденных викторин;
- XP;
- результаты по Easy;
- результаты по Normal;
- результаты по Hard;
- результаты по Expert;
- количество правильных ответов;
- количество неправильных ответов.

На основе этих данных модель определяет категорию уровня игрока:

- Beginner
- Intermediate
- Advanced
- Expert

Результаты обучения модели сохраняются, поэтому ML-часть проекта может использовать накопленную историю.

---

## 🧩 Слабая тема

Бот анализирует результаты по разным уровням сложности и может определить, где результат пользователя ниже.

После этого он показывает слабую тему и предлагает направление для дальнейшего изучения.

Например:

**Слабая тема → Гайд → Новая викторина**

Это превращает проект из обычной викторины в адаптивную систему обучения.

---

## 🔄 Адаптивная система

В проекте реализован следующий принцип:

```text
Игрок
   ↓
Викторина
   ↓
Результат
   ↓
Статистика
   ↓
ML-анализ
   ↓
Определение слабой темы
   ↓
Рекомендация гайда
   ↓
Следующая викторина
```

Таким образом, бот использует предыдущие результаты пользователя для выбора дальнейшего направления.

## 💾 Сохранение данных

Проект использует несколько файлов для сохранения данных.

### `progress.json`

Хранит прогресс:

- XP;
- уровень;
- количество викторин;
- результаты;
- статистику по сложности.

### `telegram_users.json`

Хранит состояние пользователей Telegram и данные, необходимые для работы бота.

### `ml_training_data.json`

Хранит историю данных, используемых для ML.

### `game_helper_ml.joblib`

Содержит сохранённую обученную ML-модель.

## 🔐 Безопасность токена

Telegram Bot Token вводится при запуске программы через `getpass`.

Он не должен публиковаться в README, коде или отправляться другим людям.

При запуске появляется запрос:

```text
🔐 Введи Telegram Bot Token:
```

После ввода токен используется только для запуска бота.

## ▶️ Запуск проекта

Для установки необходимых библиотек используется файл:

```text
requirements_Game_Helper_Telegram_MAX.txt
```

Команда установки:

```bash
pip install -r requirements_Game_Helper_Telegram_MAX.txt
```

После этого нужно открыть:

```text
Game_Helper_Telegram_MAX.ipynb
```

и запустить основную ячейку.

После запуска появляется сообщение:

```text
🤖 GAME HELPER TELEGRAM MAX ЗАПУЩЕН!
📱 Отправь боту /start
🛑 Остановка: Ctrl+C
```

После команды `/start` открывается главное меню.
